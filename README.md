# 🎓 Midterm Quest

Тренажёр по Academic Writing: вопросы варианта A и B, перевод, шпаргалки, XP и работа над ошибками.

Один файл `index.html`, без сборки и зависимостей. Прогресс хранится в браузере (localStorage).

## Запуск локально

Откройте `index.html` в браузере (или в VS Code: расширение **Live Server** → *Go Live*).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `midterm-quest`).
2. Загрузите `index.html` и `README.md`.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save*.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/midterm-quest/`.

## Заметка

Ключа ответов в экзаменационном файле нет, ответы выведены из материалов курса. Сомнительные места помечены ⚠️.
